# Приклад повного циклу: snapshot-freshness-badge

Документи з реального прогону SDD-lite на цьому стартері. Фіча — значок на плитці бренду,
який показує, наскільки свіжі дані: `1h ago` (fresh), `12h ago` (stale), `3d ago` (old).

| Файл | Звідки |
|---|---|
| `spec.md` | `/sdd:specify` |
| `design.md` | `/sdd:design` |
| `tasks.md` | `/sdd:tasks`, потім `/sdd:implement` відмічав виконані задачі, а `/sdd:verify` додавав нові |
| `verify-report.round-1.md` | перша перевірка: 2 важливі зауваження |
| `verify-report.round-2.md` | друга: усі критерії PASS, але тест не ловив повернення помилки |
| `verify-report.md` | третя, остання: 0 блокерів, 0 важливих, лише дрібниці |

За правилом "максимум 3 цикли" після третьої перевірки рішення про `/sdd:ship` ухвалює людина.

Коду цієї фічі в стартері немає — його пише `/sdd:implement`, коли ти запускаєш цикл сам.
На стартових даних усі бренди покажуть `old`: скани в базі датовані травнем 2026.
